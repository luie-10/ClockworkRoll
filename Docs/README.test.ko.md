# 핵심 시스템 단독 테스트 가이드

씬 세팅 없이 **핵심 시스템 전체**를 테스트하는 전용 부트스트래퍼입니다.
실제 게임 시스템 스크립트(GameManager/BattleManager 등)를 그대로 사용하므로, 여기서 확인되면 정식 씬에서도 동일하게 동작합니다.

## 실행 방법 (3단계)

1. **새 씬 생성** — File → New Scene (기본 템플릿, Main Camera + Directional Light 유지)
2. 빈 오브젝트 생성 → 이름 `TestBoot` → **`Scripts/Test/TestBoot.cs`** 부착
3. **Play**

이것뿐입니다. 코드가 알아서 다 만듭니다:
매니저 4종, 플레이어 큐브, 바닥, 테스트 카드/적/무대/챕터(런타임 생성 — 프로젝트에 파일이 남지 않음), 대사창·기력·감정·전투 로그·턴 종료 버튼·손패 UI.

## autoPlay 모드

| 모드 | 동작 |
|---|---|
| `Auto Play` **체크** | Play만 누르면 클릭 없이 AI가 대사를 넘기고, 턴마다 카드를 최대 3장 쓰고 턴을 넘기며 전투가 저절로 끝까지 진행 → **Console에서 관전** |
| `Auto Play` **해제** | 직접 클릭 플레이: 대사 클릭 → 손패 카드 클릭(노란색) → 적 큐브 클릭 → 턴 종료 버튼 |

## 테스트 체크리스트

| 테스트 항목 | 확인 방법 (콘솔 / 화면) |
|---|---|
| 스토리→전투 전환 | 인트로 대사 2줄을 넘기면 "[전투] ── 무대 [테스트 무대] 시작 ──" 로그 |
| **기력 자원** | 우상단 "기력" 숫자 — 카드 코스트만큼 차감, 턴마다 +1 회복 |
| **합 승리 시 기력 회복** | 공격 주사위로 합을 이기면 기력 +1 |
| **타입 상성** | 참격 vs 관통 합에서 "참격은(는) 관통에 강하다! 굴림 +2" 로그 |
| **동점 무효** | 같은 값 → "팽팽하게 밀렸다" 로그, 양쪽 모두 피해 없음 |
| 감정 단계 | 피해를 주고받으면 "감정 단계 상승" → 보상 카드 '감정의 칼날'(감정 2 필요) 사용 가능 |
| **책장 흡수** | 승리 시 "적의 책장 흡수" 로그 → 이후 손패에 ◈ 보라색 카드 등장 |
| **침식** | ◈ 카드 사용 시 확률적으로 "기억이 침식했다!" + 사용자 피해 |
| 이동 연출 | 합 시작 시 공격자 큐브가 상대 곁으로 걸어갔다가 복귀 |
| 아웃트로→클리어 | 아웃트로 2줄 후 "모든 챕터 클리어" 로그 |

## 연출까지 테스트하려면 (선택)

- **Main Camera**에 `BattleCamera` 부착 → 합 순간 클로즈업 연출 추가
- **Directional Light**에 `StageLighting` 부착 → 감정 단계가 오를수록 빛이 붉게 변함

## 주의

- 반드시 **빈 씬**에서 단독 사용 — 정식 씬 세팅(`README.ko.md`)과 같이 쓰면 UI가 겹칩니다
- UI 한글은 유니티 내장 폰트의 동적 폴백으로 렌더링됩니다 — 에디터 테스트는 정상, 실제 빌드에는 폰트 에셋 필요
- 테스트용 카드/적/무대/챕터는 코드가 런타임에 생성한 것이라 씬을 나가면 사라집니다 (프로젝트 오염 없음)
- 세이브가 없으므로 다시 Play하면 덱이 시작 덱으로 리셋됩니다
